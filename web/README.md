# 🕉️ Velmount Murugar Temple Website

A beautiful and modern website for Velmount Murugar Temple located in Altamont Pass, California.

## ✨ Features

- 🏠 **Home Page** - Welcome section with temple overview and timings
- 📖 **About Page** - Detailed temple information, location, and facilities
- 🎉 **Events Page** - Interactive festival calendar with descriptions
- 🖼️ **Gallery Page** - Beautiful temple photo collection
- 📞 **Contact Page** - Contact form and temple information
- 📱 **Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- ✨ **Smooth Animations** - Beautiful fade-in and slide-up effects
- 🎨 **Modern Design** - Clean and elegant UI with temple theme colors

## 🛠️ Technologies Used

- **React** - Frontend framework
- **React Router** - Page navigation
- **Tailwind CSS** - Styling
- **Vite** - Build tool

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd velmount/web
```

2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm run dev
```

4. Open browser and visit `http://localhost:5173`
